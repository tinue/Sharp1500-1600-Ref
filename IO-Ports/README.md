# I/O Ports

Port maps and what the bits do. Today this is PC-1600 only: range map, the LH5810-compatible block 10-1FH, interrupt causes 32H/35H, buzzer, timer/RTC/analog, and the memory-management ports.

**See also:** `../Serial-Parallel/` (TC8576 at 20-23H), `../Display/` (LCD ports 50-5BH), `../Storage/PC-1600-Floppy-CE-1600F.md` (floppy ports 78-7FH), `../Peripherals/` (printer ports 80-83H), `../Memory/PC-1600-Bank-Switching.md`.

**Gaps:** a PC-1500 I/O document (`OUT`/`IN` ports, LH5810 as used by the CE-150) is missing; the CE-150 side is in `../Peripherals/PC-1500-CE-150-Hardware.md`.
