# PC-1500 LH5811 and the ME1 Space

Summary: Where the PC-1500's own LH5811 answers in ME1, what unclaimed ME1 reads, the buzzer on PC6 and its measured tone timing.
Scope: PC-1500, PC-1500A (PC-1600: ../CPU/PC-1600-LH5803-Memory-View.md, ../IO-Ports/PC-1600-IO-Ports.md)
Sources: ROM:PC-1500-ROM/disasm/a04/PC-1500-A04.asm; TRM-1500 PDF p.77 (F register); measurements on a real PC-1500 and PC-1500A by the maintainer (2026)
Status: draft

## 1. Scope

This is the start of the PC-1500 I/O document that `../Open-Questions.md` lists as missing. It
holds what was measured on real units while the Calc-U-1600 emulator was built; the full
LH5811 register description (TRM) is not transcribed yet. The CE-150's own LH5810 is in
`../Peripherals/PC-1500-CE-150-Hardware.md`.

## 2. ME1 decode

| Address (ME1) | What answers | Measured |
|---|---|---|
| F000–FFFF | the internal LH5811 | `PEEK# &F00C` = 8; `PEEK# &700C` = 255, so it decodes F000H up only |
| F000–F003 | nothing: the LH5811 has no register there | `PEEK# &F002` = 255 |
| everything else | nothing | `PEEK# &111`, `&7C02`, `&C000` = 255 (PC-1500A) |

- **Unclaimed ME1 reads FFH and writes are dropped.** Internal RAM, display RAM, the ROM and a
  CE-163F module decode ME0 only.
- **40-pin modules never see ME1:** the S strobes are ME0-qualified
  (`../Memory/PC-1500-Address-Decoding.md` §2.4), and the CE-155/CE-159 Y0 chip gates on DME0.
- The PC-1600 differs: there, unclaimed ME1 keeps the last byte on the bus
  (`../CPU/PC-1600-LH5803-Memory-View.md`).

## 3. Buzzer (OPC bit 6)

The buzzer hangs on the LH5811's port C, **PC6** = bit 6 of OPC at ME1 F008H. `BEEP` drives
it in a timed loop; BEEP OFF clears the bit (`ani #(0xF008),0xBF` at E65BH)
[ROM:PC-1500-ROM/disasm/a04/PC-1500-A04.asm@E655].

| Quantity | Value | Source |
|---|---|---|
| Tone period | **(164 + 22·A) CPU cycles** at 1.300 MHz | measured on a real PC-1500 (audio recording) |
| Tone period, per the ROM loop | (161 + 22·A) cycles | cycle count of the A04 loop; the TRM's figure agrees |
| Pause between repeats | 7 edges of the uPD1990AC's TP signal (routine at E88CH); real repeats are whole 64ths of a second | ROM; recording |

The loop is identical in A01, A03 and A04, so the extra 3 cycles per period come from the
hardware. Unresolved: the loop's 3 ME1 accesses per period would fit one extra cycle each, but
that rule would slow BASIC by only 0.007 %, so it does not explain other timing measurements.
Proposed test: time a loop of only ME1 reads against one of ME0 reads.

## 4. F register: the tone and tape divider

The LH5811's F register selects the modulated serial output (F6) and two dividers, F0–F2 = FX and
F3–F5 = FY, each φ/64 to φ/1024 [S:TRM-1500 p.77]. On the PC-1500 the LH5811 runs at φ = 1.3 MHz:
the CE-150's tape code writes F = 63H and records 2.54 / 1.27 kHz tones. The PC-1600 runs the
same block at 325 kHz under the Z-80 and at 1.3 MHz under the LH5803
(`PC-1600-IO-Ports.md` §2.7).
